Requirements
  System Requirements
  Java 11
  Python 3.10+
Instalasi dependensi python
  pyspark 3.5.1
  spark-nlp 5.2.2
  numpy
  pandas
Langkah langkah menjalankan 
1. python save_parquet.py
   (Menyimpan data dengan format parquet untuk efisiensi)
2. python check_parquet.py
   (Mengecek apakah data berhasil disimpan sebagai parquet dan formatnya sesuai)
3. python train_model.py
   (Melatih model)
5. python acuracy.py
   (Mengecek akurasi model berdasarkan data training)
6. python prediction.py
   (Melakukan predisksi dan menyimpan dalam bentuk csv)
